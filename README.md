📝 Descrição do Projeto

O PetAdopt é uma plataforma web responsiva desenvolvida como projeto acadêmico para o Laboratório de Front-End. O objetivo do sistema é estabelecer um ecossistema digital que conecta de forma simples e intuitiva potenciais adotantes a ONGs e protetores independentes que resgatam animais de rua.

A aplicação foca na separação de responsabilidades (Separation of Concerns), utilizando as tecnologias fundamentais da web (HTML5 semântico, CSS3 responsivo e JavaScript Vanilla de alto desempenho) sem a dependência de frameworks complexos, garantindo leveza e acessibilidade.
